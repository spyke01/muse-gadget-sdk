# Theme and avatar PR evidence

Native 466 x 466 framebuffer captures from a Waveshare ESP32-S3-Touch-AMOLED-1.75C. These show the integrated development firmware before the PR branches were rebased onto upstream 7dd409b.

- ui-dark.png and ui-light.png: the built-in avatar under the two manual appearance choices.
- personal-idle.png: the personal avatar after a 15-second visit to Settings.
- personal-tap.png: the same personal avatar during local pet feedback.

The personal screenshots correspond to the source validated as 63a4186. They use a 192-pixel, 20 fps, CRF 20 phone-avatar pack; screen captures are still frames, not a frame-rate measurement. No phone MP4s, account identifiers, credentials, or device backups are included.
